## Sherpa-ONNX voice model files

Prompt downloads the selected voice model files from Hugging Face only after an explicit user action. The files are fetched from the pinned repository revisions below; the host is not changed to a third-party mirror.

- French: `https://huggingface.co/shaojieli/sherpa-onnx-streaming-zipformer-fr-2023-04-14`, revision `3db9565d9633758d6b87b9a7b3dc09ebfb6b2c73`.
- English: `https://huggingface.co/csukuangfj/sherpa-onnx-streaming-zipformer-en-2023-06-26`, revision `672fbf1b30579d6585301139bb363f42a0ad4a24`.

The model repositories and their files may have separate terms. No model-file license or redistribution authorization has been established in this worktree; Prompt does not make that claim. Users should review the applicable Hugging Face repository and file metadata before redistribution.
